Vagus Course Style Guide

Every diagram in the course follows these rules, so she learns the visual code once and then reads each new figure without decoding it. Each rule comes with the reason it helps learning.

Colour legend

One meaning per colour, everywhere. At most 5–6 colours in one diagram. Colour is never the only signal: each colour has a written label and, where useful, a pattern or line style, because about 1 in 12 men has a red-green colour-vision deficiency and arteries, muscle and lesion would otherwise blur together.

Nine rules

  1. Use the colour code above, identically in every figure.

    A stable colour-to-meaning mapping lets colour act as a signal rather than something to decode, which cuts extraneous cognitive load. Following atlas convention (yellow nerves, red arteries) means Sobotta and Prometheus plates look familiar.

  2. Use the shape code above for every schema and flowchart.

    When structure, function and decision always look different, she sees the logic of a flowchart before reading a word. Learned once, it works for the whole course.

  3. Label on the structure, keep one orientation, flow one way, leave space. Labels sit on or right next to what they name, never in a separate key. Anatomical views are always anterior (patient facing you, so the patient's right is on your left) or superior for the glottis, with anterior at the top and R / L printed in the patient's frame. Flow runs left to right or top to bottom.

    Spatial contiguity is one of Mayer's most robust principles: separated labels force the eyes back and forth and split attention. Endoscopic images are the exception, because their orientation differs between examination methods; they always carry R/L markers taken from the source.

  4. Signal one thing. The teaching point gets the bold outline or full saturation; everything else is muted grey.

    Signalling guides attention to the essential element. Several highlights in one figure cancel each other out.

  5. No decoration. No clip art, stock photos, mascots or background images. Every visual must teach something.

    Mayer's coherence principle and the seductive-details research (Rey 2012) show that interesting but irrelevant images reduce learning.

  6. Build complex figures in 2–4 stages, for example cartilages → muscles → nerves → lesion.

    Segmenting and pre-training keep the number of new elements per step within working memory, which matters in anatomy, where every element interacts with the others.

  7. Reuse the same figure for the same concept. The master map below returns in every lesion section, with only the lesion added.

    Seeing the same layout again strengthens one mental model and makes the figure itself a retrieval cue in the exam.

  8. Give key figures a hand-drawing prompt: a simplified version she redraws from memory, step by step.

    Drawing from memory combines retrieval practice with generative learning (Fiorella and Mayer 2016), which works better than rereading the finished picture.

  9. Code first, real images where realism matters. Schemas are Mermaid or SVG so they can be edited and kept consistent. Laryngoscopy, stroboscopy and 3D anatomy are not redrawn; each gets a look-up card saying exactly what to find and where.

    Simple schematic drawings teach structure well, but recognising a paralysed fold needs real images and video.

Example: nerve → muscle → action map

The core figure of the course, drawn by the rules above. Step through the build-up; stage 3 is the complete reference map.

Hand-drawing prompt · redraw from memory
  1. Draw a yellow box “N. vagus” on the left.
  2. Split it: two teal boxes on top (R. externus, R. internus = SLN), one violet box below (RLN).
  3. From R. externus, one arrow to “CT”. From R. internus, an arrow pointing back from “sensation above”.
  4. From RLN, four arrows: PCA, LCA, IA, TA. Add “sensation below” pointing back.
  5. Write one action per muscle. Box the PCA and write “only opener”.
  6. Check against the map. Anything missing becomes a flashcard.
